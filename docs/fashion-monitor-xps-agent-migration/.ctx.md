## CLAUDE.md
Execution-routing doc. Deploy target is desktop-agent (moving to xps-agent, this feature),
never this Mac checkout. `make sync`/`make push`/`make deploy` ship images/config over SSH.
Deployed copy: dedicated `fashionmonitor` service user, `/opt/docker/fashion-monitor`. Live
data: SQLite DB + `data/poshmark-profile` (no cookies persisted yet). `scraper`/`poshmark`
route through home-infra's scraper-egress VPN tunnel (`network_mode: container:gluetun-scraper`)
and never touch the LLM; `score` stays off the tunnel to reach the LAN Ollama broker. Live
scrapes are opt-in only (`pnpm run verify:scrapers`/`test:live`) — never run casually from the
Mac clone; this feature extends that caution to verifying a freshly-redeployed host instance too.

## CONTEXT.md
Fashion Monitor: personal resale monitoring tool, multi-platform scrape + LLM scoring + ntfy
alerts. Controlled-vocabulary terms: Monitor (saved search), Taste (aesthetic config),
User/Profile/Role (multi-tenant web app, Profile scopes DB rows via profile_id), Connection
(per-profile per-platform credential link), Pipeline (scheduled scrape+dedupe+filter+score+alert),
Secret (encrypted-at-rest credential).
